To reset events, you can...

* Use the [Event Lookup](https://www.nexusmods.com/stardewvalley/mods/8505) mod
* Use the [Event Repeater](https://www.nexusmods.com/stardewvalley/mods/3642) mod
* Edit the save file. See [Save File Editing Guide by ConcernedApe](https://community.playstarbound.com/threads/save-file-editing-guide-for-solving-some-common-issues.110762/)
