Working memory holds a limited number of elements. According to Cognitive Load Theory, these items are taken up by three kinds of load.[^1] they are [[Intrinsic load (Cognitive Load Theory)|intrinsic load]]  (the number of the elements needed to process), [[Extraneous load (Cognitive Load Theory)|extraneous load]] (the number of elements that are not related to the learning task), and [[Germane load (Cognitive Load Theory)|germane load]] (the effort to form the memory).
