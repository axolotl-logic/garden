
MC/DC is a code coverage criterion. It specifies what is meant by coverage and what should be covered. It calls out entry and exit points, decisions, conditions, and outcomes.

100% MC/DC coverage is required for safety-critical software by NASA.

> 3.7.4 If a project has safety-critical software, the project manager shall ensure that there is 100 percent code test coverage using the Modified Condition/Decision Coverage (MC/DC) criterion for all identified safety-critical software components. [^1]
