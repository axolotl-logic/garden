A difficult situation is an opportunity to practice skills. I have tried to help myself by facing difficult things with the thought that I would build an emotional callous. However, this model is both passive and, where not passive,  self-flaggilatory. It presupposes a situation as "bad" with goodness derived from the ability to face it in the future. This puts suffering as desirable. Alternatively, it is an opportunity to improve at  a natural ability. This implies that there is an action that is being done. One might think of these as skills.
