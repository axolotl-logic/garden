Working memory holds a limited number of elements. According to cognitive load theory, these items are taken up by three kinds of load.[^1] Intrinsic cognitive load is the number of the elements needed to process. Extraneous cognitive load is the number of elements that are not related to the learning task. Germane load represents the effort to form the memory.
